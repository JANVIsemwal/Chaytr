## About

The official website of **Chaytr**, a technology startup working across **AI / ML, Embedded Systems,
Robotics and Fintech**. Built with React Native and Expo, and deployed on Vercel.

## Products

**NexPay:** a temporary UPI wallet for foreign visitors to India. Load money at a fair exchange rate, pay at
any UPI QR, and cash out what is left before flying home. No Indian bank account needed.

**Bhedak:** a handheld radar that finds a hidden, armed person through dense forest and warns soldiers with
a silent vibration.

## Run locally

Requires **Node.js 20+**.

```bash
npm install
```

```bash
npm run dev
```

Open http://localhost:8081.

## Deploy on Vercel

1. Go to [vercel.com](https://vercel.com) → **Add New → Project** and import this repository.
2. Set the framework preset to **Other**.
3. Click **Deploy**.

The build settings are already in `vercel.json`. Every push to `main` redeploys the site.
